# claude-skills

Skills I've built for Claude from my own repeatable workflows.

| Skill | What it does |
| --- | --- |
| [ai-source-triage](ai-source-triage/) | Triage, dedupe, and digest AI videos and articles so you only spend time on the ones worth it. |

## Install

Each folder is one skill. Copy the folder into `~/.claude/skills/` for Claude Code, or zip it and upload it under Settings, then Skills, in the Claude apps.
